# Gwent template review v1

Preview only. No game assets are replaced. No commit or push.

310 × 585 pixels, matching supplied source dimensions. Illustration beneath frame; power, row, abilities, faction emblem, name and quote are independent layers. Quote is literary text only and remains empty when absent. Mechanics must never populate it.

Generated materials: built-in image_gen, original supplied cards as references. The generative outer gold perimeter was removed from these composited templates; only the original horizontal separator is retained. The center illustration window has verified alpha.

This is a draft base, not a verified pixel-perfect replica. Typeface, exact ribbon texture and extracted ability crops need visual sign-off. New custom abilities have no original client icon; no unrelated icons are assigned.

Audit: 156 unique missing faces, five existing faces with changed printed data in extended rules, seven faction backs currently represented by SVG crests. See art-audit.json.
