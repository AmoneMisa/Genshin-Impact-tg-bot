# Location scene expansion, 2026-10-16

Reference screenshots are kept here for visual comparison only. Page links, image URLs and local filenames are recorded in `sources.js`. Hunting references come from L2Vika location galleries; city references come from Linedia. Exact screenshot client builds are unspecified: these are not verified High Five captures. The official Gracia Final promotional reference and the Seed of Annihilation screenshot support the Gracia studies. Existing epic arena references are listed per image in `webapp/art/world/scenes/expansion.source.js`.

The 34 new illustrations were generated individually with the built-in OpenAI imagegen tool. They preserve the location palette, terrain, vegetation, architecture and main landmarks, adapted around a traversable room. They do not reproduce client UI, watermarks, items or original geodata. Full prompts, reference paths and generated source filenames are preserved in `expansion.source.js`; `scripts/ui/build-scene-expansion.py` only resizes/encodes the generated pictures and creates review sheets.

Runtime art has desktop (1536×1024) and mobile (768×512) WebP variants. Reference screenshots and source metadata are not imported by the game. Gracia has four visual studies but no coordinates or travel routes in the server catalog; the Atlas explicitly presents it as an overview. City illustrations are decorative Atlas previews; original map geometry remains authoritative.

Review sheets: `docs/scene-expansion-hunting.jpg`, `scene-expansion-epic.jpg`, `scene-expansion-city.jpg`, `scene-expansion-gracia.jpg`.
