# Референсы боевого интерфейса Lineage II

Просмотрены 16 октября 2026. Это справочные снимки интерфейса; они не загружаются игрой и не подменяют оригинальные клиентские иконки.

- [Архив руководства NCsoft: интерфейс](https://legacy-lineage2.com/guide/interface.html): эффекты справа от статуса, группа с выбором союзника и переключением размера. Архив исторического руководства, а не подтверждение точных размеров пикселей H5.
- `party-classic.jpg`: [снимок партии Lineage2Dex](https://forum.lineage2dex.com/data/attachments/4/4168-c00c00bf17ede23140583f799d440105.jpg). Плотная сетка изображений эффектов, узкая группа у края, свой статус отдельно.
- `party-asterios.png`: [снимок Asterios](https://forum.asterios.tm/uploads/monthly_2025_10/image.png.e8e646615378de9bb9f64c58abd59607.png). Участники без отдельных закруглённых карточек; тонкие полоски ресурсов, узкая вертикальная компоновка.
- `party-mini-options.png`: [настройки Euro-PvP](https://euro-pvp.net/images/abaut_x100/upd_26/party_light_1_eng.png). Видна настройка Small Party Window. Это модифицированный клиент; снимок не используется как доказательство нативных размеров High Five.
- `party-afterwork-1.webp`, `party-afterwork-2.webp`, `party-afterwork-3.webp`: [страница автора интерфейса на базе High Five](https://l2afterwork.com/wiki/interface/#party), раздел Party. Снимки: [1](https://l2afterwork.com/static/img/interface/party-l2-after-work-1.aa1eaded6329.webp), [2](https://l2afterwork.com/static/img/interface/party-l2-after-work-2.ebf460e213af.webp), [3](https://l2afterwork.com/static/img/interface/party-l2-after-work-3.d32c172d87d9.webp). Дополнительные уровни, Gear Score и эффекты этого сервера не переносятся в проект.

Адаптация проекта: оригинальные опубликованные иконки эффектов, плотные ряды без таймеров поверх рисунка; мини-пати с именами и CP/HP/MP; 8 союзников плюс отдельный статус своего персонажа. Мобильные размеры 14–16 px и 26 px для строки группы — размеры адаптации. Механики и вместимость эффектов этим изменением не затрагиваются.
