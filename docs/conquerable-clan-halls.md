# Захватываемые клан-холлы

Шесть КХ доступны через слой захватываемых клан-холлов общего Атласа:

| КХ | Сценарий |
| --- | --- |
| Крепость Сопротивления | Убийство Нурки, победа по суммарному урону клана |
| Разорённый замок | Регистрация и победа по урону главному NPC |
| Крепость Мёртвых | Регистрация, ночной бой и победа по урону главному NPC |
| Цитадель Бандитов | Выбор защитника, отбор и финал против владельца |
| Заповедник Диких Зверей | Выбор защитника, отбор и финал против владельца |
| Дворец радужных источников | Декреты, группа клана, буквы и предметы для тыквы |

Сервер проверяет физическое прибытие ко входу, регистрацию, состав участников и владение. Общий захват флага не применяется к этим шести КХ. Отзыв заявки освобождает именно её позицию: последующие участники не появляются на месте другого защитника.

Владелец входит во двор и через дверь проходит во внутренний зал. Внешний вид зала связан с существующей прокачкой клана 1–5; цена и требования берутся из `functions/game/clans/clanHall.js`. Прокачка сохраняется в клане. Рисунки окружения — художественная адаптация, не оригинальные клиентские текстуры или геодата. Для телефонов предусмотрены отдельные WebP; действия доступны и при отказе canvas.

Данные сценариев опубликованы в `template/hallScenarios.js`. Импортёр `scripts/l2j/import-hall-scenarios.py` использует локальный снимок L2J Mobius High Five `9fb01cb20513e55190cdde8d91e41be2c0914f84`: SQL клан-холлов, Java-сценарии и NPC/skill XML. Записи содержат пути исходников и SHA-256. Для повторного импорта нужен этот снимок в `.tmp/world-source/h5-data` и сопутствующие исходники импортёра.

Остаётся ограничение: получение декретов `8034` через рыбалку не реализовано. Сервер требует реальные декреты в сумке; произвольная выдача или выдуманный шанс не добавлены. Поэтому естественное получение доступа к этому соревнованию требует отдельного завершения рыбалки. Оплата квестовым документом для двух соревнований защитников также требует уже имеющийся документ; реализация сценария захвата сама по себе не добавляет исходные квесты его получения.

Проверки:

```powershell
node --test test/hall-conquest.test.js test/clan-hall.test.js test/clan-hall-auction.test.js test/world-systems.test.js test/scene-expansion.test.js
node scripts/ui/check-hall-locations.mjs
```

Браузерный прогон проверяет регистрацию, двор, дверь, пять уровней, выход и захват Нурки на ширине 320, 390 и 1100 px, с reduced motion. На 320 px дополнительно отключает canvas и проверяет доступность прохода. Скриншоты сохраняются в `.tmp/hall-locations-ui`. Эти проверки используют локальные фикстуры; они не подтверждают работу живой MongoDB или развёрнутого сервера.
