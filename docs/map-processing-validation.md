# Проверка базовой карты — 20 октября 2026

Обработаны все 72 неинстансовые зоны текущего каталога: 39 наземных пространств с непрерывной ходьбой и 33 отдельных пространства. Дополнительно подключены 11 наземных зон; каждая сохранена отдельным коммитом. Структурный отчёт: [обработка карты](map-processing.md).

## Результаты

| Проверка | Результат |
| --- | --- |
| `node scripts/ui/report-map-processing.mjs` | 72 зоны, 149 этажей/участков, 1624 комнаты, 166 межэтажных переходов, 214 вариантов окружения |
| `node --test --test-skip-pattern='^arena auto-fight:'` | 1601 тест пройден, ошибок нет |
| `node scripts/ui/check-location-levels.mjs` | По 152 случая на 320/390/1100 px: все 149 этажей/участков, включая четыре состояния Хеллбаунда; ещё шесть случаев без WebGL, Phaser или рисунков |
| `LOCATION_LEVEL_ZONE=<11 добавленных зон> node scripts/ui/check-location-levels.mjs` | 66 случаев: каждая зона на трёх ширинах и в трёх дополнительных режимах на 320 px |
| `LOCATION_LEVEL_ZONE=brekas-stronghold node scripts/ui/check-location-levels.mjs` | Шесть случаев, включая выбор свободной земли рядом с маркерами NPC |
| `node scripts/ui/check-world-settlements.mjs` | Все восемь поселений на трёх ширинах; исходные тайлы, подход к NPC, ходьба/выход из холла, управление без Canvas, закрытие окон |
| `node scripts/ui/check-missing-world.mjs` | Грация, фильтр Атласа, предмет и плата Ишумы, подтверждение и восстановление фокуса на трёх ширинах |
| `python -m py_compile scripts/l2j/import-missing-world.py` | Синтаксис импортёра проверен |

Два длительных теста `arena auto-fight:` не запускались повторно в этом прогоне; они проходили на предыдущем этапе работы. Браузерные сценарии используют локальные тестовые сессии и настоящие серверные обработчики, без обращения к рабочей базе.

При сравнении данных 11 локаций с предыдущей версией подтверждено, что изменена только отметка наземного пространства. Исходные NPC, характеристики, спавны, этажи, мировые координаты, точки входа и цены сохранены.

Обнаруженное зависание поселений исправлено в `b1e25bd1`: запросы видимых тайлов теперь укладываются в ёмкость кеша. Регрессия воспроизводит загрузки и повторные отрисовки с ограниченным кешем; очередь загрузки должна опустеть. Готовый широкий обзор и управление также проверены в браузере.

## Оставшиеся границы реализации

Проверка относится к текущему каталогу и базовой карте. Она не подтверждает перенос всех территорий High Five, полных сценариев Seeds/Хеллбаунда/башен, кормления зверей или квестовых наград. Региональная склейка разных локаций, дальние маршруты за окном девяти участков и согласованная общая композиция окружения остаются незавершёнными. Для исходной геометрии межлокационных проходов нет файлов геодаты и проверенных коридоров; произвольные точки вместо них не добавлены.
