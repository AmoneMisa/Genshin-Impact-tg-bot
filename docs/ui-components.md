# Общие компоненты интерфейса

Обязательное правило находится в корневом `AGENTS.md` и распространяется на все экраны.

| Элемент | Основной компонент |
| --- | --- |
| Цвета, фоны, границы, состояния, скругления | `webapp/design-system.css` |
| Кнопки действий | `.ui-button`, `.primary`; общие правила для существующих семейств действий |
| Поля и textarea | Общие правила стандартных HTML-контролов в дизайн-системе |
| Чекбоксы и радиокнопки | Общие правила input, включая checked, indeterminate, disabled и focus |
| Селекты | `webapp/design/select.js`, глобальный `observeSelects` в `webapp/app.js` |
| Вкладки папками | `.ui-folder-tabs`; размеры через `--tab-height`, `--tab-font-size` |
| Попапы | `.game-dialog-panel`, `webapp/dialog-heading.js`, `webapp/overlay-a11y.js` |
| Количество и подтверждение операций с предметами | `webapp/stock-quantity.js` |
| Сетки инвентаря, магазинов, обмена и хранилищ | `webapp/item-grid.js`, `webapp/item-grid.css` |
