# Исходные переходы и двери Пагана

`template/paganAccess.js` воспроизводимо импортирует `PaganTeleporters.java` и шесть фиксированных NPC из `spawns/Others/19_16.xml` и `21_16.xml`. Версия High Five — `9fb01cb20513e55190cdde8d91e41be2c0914f84`; SHA всех трёх файлов закреплены. Адаптированные переходы `paganRoutes.js` используют эти данные вместо повторения координат.

| NPC | Исходный XYZ | Действие |
| --- | --- | --- |
| 32039 | 34842, −49756, −763 | При первом разговоре бесплатно переносит в −12766, −35840, −10856 |
| 32040 | −11986, −35903, −10857 | При первом разговоре бесплатно переносит в 36640, −51218, 718 |
| 32034 | −15934, −36605, −10693 | Открывает 19160001 при наличии хотя бы одной проходки 8064, 8065, 8067 |
| 32035 | −16722, −36928, −10725 | Открывает 19160001 без проверки проходки |
| 32036 | −15853, −43811, −10685 | Открывает 19160010 и 19160011 при наличии метки 8067 |
| 32037 | −16629, −44290, −10725 | Открывает 19160010 и 19160011 без проверки проходки |

Проходки не расходуются. Для дверей исходный скрипт назначает закрытие через **10000 мс**. Эти правила сохранены как данные для дальнейшего переноса; мировой сценарий дверей ещё не включён. Наличие таблицы не открывает двери текущему наземному движку.

Паган по-прежнему использует адаптированные комнаты. Прыжок из церкви остаётся явно помеченным `authored-drop`, его исходная позиция — `null`. Точка возврата зеркала 32040 не выдаётся за исходную точку прыжка. Обе стороны имеют реальные слои геодаты, но ограниченная проверка между ними с пределом 200000 узлов, шагом 4, запасом 2048 и весом эвристики 2 исчерпала бюджет как для обратимого пути, так и для направленного. Это не доказывает отсутствия пути и не разрешает подменять прыжок произвольным телепортом. Для завершения нужны проверенные спуск, вертикальная физика, двери с проходками и перенос населения галерей.

Генератор: `python scripts/l2j/import-pagan-access.py`. Проверки исходных правил и сохранения прежних переходов: `node --test test/pagan-native-route.test.js test/location-levels.test.js`.
