# Раздельные боевые характеристики

Персонаж использует четыре независимых значения: `pAtk`, `mAtk`, `pDef`, `mDef`. На экране персонажа и в выборе класса они представлены в две колонки.

Тип навыка выбирается из явного `damageType` или исходных данных Lineage II; для старых навыков без метаданных используется семейство класса. Физический удар использует P.Atk/P.Def, магический — M.Atk/M.Def. Это применяется в арене, рейдах на игроков, полевом PvP, охоте, боях с боссами и их свитой. Тип также определяет расход зарядов и действие немоты.

Броня и щиты дают физическую защиту, украшения — магическую. Второй тип атаки оружия рассчитывается из исходного соотношения P.Atk/M.Atk с сохранением игровой шкалы. Раздельно учитываются STR/INT, пассивные навыки, клановые навыки, Might/Shield/Empower, способности камней жизни и Soul Crystal. Снижение брони уменьшает только физическую защиту.

Старые сохранения с `attack`/`defence` продолжают работать: оба канала используют прежнее базовое значение до обновления характеристик. Новые шаблоны пока наследуют эти базовые значения; независимый баланс профессий можно настраивать через четыре новых поля. Разделение бонусов экипировки и эффектов меняет итоговые характеристики по их назначению.

Версии шаблонов и контрольные суммы обновлены для загрузки новых данных из файлов в MongoDB. Изменения подготовлены локально; запуск сервера и обновление рабочей базы не выполнялись.

Проверки: полный прогон — 935 тестов без ошибок; дополнительные проверки типов урона, профиля и PvP. Браузерная проверка на ширине 320/390 px, включая значения до 2 147 483 647; результаты — `ui-check.json`, снимки — в этой папке.

Исходный аудит интерфейса, безопасности и производительности: [REPORT.md](../audit-2026-10-11/REPORT.md). Его остальные замечания остаются отдельными задачами.
