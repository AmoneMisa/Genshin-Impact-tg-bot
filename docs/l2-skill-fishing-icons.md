# Иконки навыков и рыбалки

Оригинальные PNG из предоставленной папки `icons` опубликованы как lossless WebP 32×32, 64×64 и 128×128. Цвета и пиксели клиента сохранены, увеличение — nearest neighbour. Исходные изображения снаряжения не изменяются.

Галерея: [навыки и рыбалка](l2-skill-fishing-icons-preview.html). Машинный список соответствий: [references](l2-skill-fishing-references.json).

Источник ID и полей `icon`: [L2J Mobius High Five](https://gitlab.com/MobiusDevelopment/L2J_Mobius/-/tree/9fb01cb20513e55190cdde8d91e41be2c0914f84/L2J_Mobius_CT_2.6_HighFive/dist/game/data/stats). Файлы клиента предоставлены пользователем.

- Семь баффов: точные иконки Might 1068, Shield 1040, Haste 1086, Focus 1077, Guidance 1240, Death Whisper 1242, Wind Walk 1204.
- Все 91 авторских названия навыков сопоставлены с иконками близких по смыслу умений L2. Это визуальные аналоги, не утверждение о совпадении механик.
- Все 16 умений ЛС используют значки High Five по типу: активные `icon.skill3123`, пассивные `icon.skill3238`, срабатывающие `icon.skill3080`. Изменённые проектом эффекты не объявлены точными копиями оригинальных навыков.
- Пассивные, клановые и боевые эффекты также используют клиентские изображения. Статус сохраняет `potionId`, чтобы разные баффы с одинаковой характеристикой показывались своими иконками.
- Все 367 предметов из текущих данных рыбалки: рыбы, удочки NG–S, наживка, заряды, масла, чешуя, кости, самоцветы, доказательства улова и рецепты. Рыбы разных уровней могут использовать одинаковую оригинальную иконку, как в клиенте.

Перегенерация:

```powershell
node scripts/l2j/import-skill-fishing-icons.mjs <папка PNG> <папка XML предметов> <папка XML навыков>
python scripts/l2j/publish-skill-fishing-icons.py
```

Проверки: `test/l2-skill-fishing-art.test.js` — полнота соответствий, формат файлов, канонические баффы, родные значки ЛС и сохранение идентичности баффа в бою. `scripts/ui/check-l2-skill-fishing.mjs` — загрузка галереи и окон навыков, баффов, пассивных умений и рыбалки при ширине 320, 390 и 1100 px. В окне рыбалки секции расположены вертикально, чтобы рамка боя не сжимала текст.
