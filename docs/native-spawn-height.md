# Исходная высота фиксированного NPC

Закреплённый High Five `Spawn.java` корректирует Z наземного монстра по геодате только при расстоянии **строго меньше 300**. При расстоянии 300 и больше он сохраняет исходный Z. Предыдущая реализация проекта ошибочно считала этот порог запретом появления NPC.

Исправление сохраняет исходные XY и применяет исходное правило Z. Оно возвращает четыре позиции Сел Махум и три позиции Забытых равнин. Геодата не изменяется, ближайшая проходимая клетка не подставляется. Отсутствующие данные, закрытый NSWE, вода, двери и владения по-прежнему могут запрещать наземное размещение.

Исходные высоты, отличающиеся от ближайшего слоя, перечислены отдельно в [сверке](native-field-readiness.md) и её JSON-поле `retainedSourceHeights`. Сохранение исходного Z не утверждает совпадение слоёв и не разрешает движение сквозь рельеф. Движение и видимость остаются отдельными проверками.

Сохранения со старым отказом `source_ground_unavailable` мигрируют один раз по версии правила размещения. Повторно рассматриваются только фиксированные точки с расхождением высоты, которые проходят текущие проверки размещения. Загруженные NPC, их HP, случайные группы и зарезервированные возрождения не пересоздаются. Вода и владения не обходятся миграцией.

Полный исходный `Spawn.java` сохранён в `art-source/geodata/spawns/Spawn.java`; его SHA-256 закреплён импортёром в `groundSpawnHeight`. Оригинальные байты сохраняются Git без преобразования переводов строк.

Проверки: `node --test test/native-spawn-height.test.js test/native-field-registry.test.js test/native-source-gaps.test.js`. Проверены все семь исходных позиций, границы ±299/300/301, сохранение и загрузка старого отказа, отсутствие дублей и сохранение чужого HP. Сел Махум и Забытые равнины проходят браузерный сценарий мирового боя на 320/390/1100 px, без Canvas и без рисунков на 320 px. Проверка полигонов против оригинального Java по-прежнему даёт 27256 совпадений.

Общая регрессия: 1846 тестов без ошибок; два длительных сценария `arena auto-fight:` исключены из этого прогона.
