Прежние картины — иконки в стиле L2

256 отдельных иконок. Слева — размер 32×32, справа — самостоятельный вариант 64×64. Красный фон оружия и щитов, зелёный фон брони, холодный фон бижутерии; без встроенной массивной рамки, сдержанный цвет и диагональное размещение клинков и посохов. Большие исходные картины сохранены. Фоны восстановлены по оригинальным иконкам L2; это реконструкция, не отдельные текстуры клиента.
