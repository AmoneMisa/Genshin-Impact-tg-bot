# Рабочий инвентарь по согласованному референсу

Новый дизайн внедрён в webapp/inventory.js. Персонаж в полный рост и слоты экипировки слева; сумка справа. На узких экранах блоки размещаются друг под другом.

Слоты — 44×44 px, изображения — 40×40 px, без видимых подписей. Верх/низ рядом; цельная броня связывает два слота. Левая и правая руки напротив друг друга. Рубашка, пояс, аксессуары, браслет и три тату показаны по последнему утверждённому расположению.

Фильтры оформлены вкладками папок с общей нижней линией. Сумка использует общий компонент item-grid; надетые вещи исключены. Описание и надевание/снятие — в диалоге, без расширяемого блока снизу. В нижней панели три иконки действий и отдельный выброс справа; отображается только адена. Кристаллизация и выброс требуют подтверждения.

Браузерные проверки: 320, 390, 540, 820 и 1100 px (разные сценарии). Надевание/снятие, заполнение обеих ячеек цельной брони, поиск, фильтры, применение зелья, отмена/подтверждение выброса и кристаллизации, открытие аукциона и крафта. Превью сняты с реальной реализации на тестовых предметах каталога.

Полный набор проверок проекта: 1034 теста пройдены.
