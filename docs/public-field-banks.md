# Сохранение публичных локаций при выходе из Атласа

Банки населения сохраняются для всех 72 публичных зон текущего каталога. Ранее сохранение было привязано к наличию наземного маршрута; катакомбы, некрополи и часть связанных подземелий теряли банк при выходе. Повторный вход мог пересоздать NPC.

Свиток возвращения, оплаченный телепорт, вход из церкви Руны и переход в следующее связанное подземелье теперь используют общий сохраняемый банк. Возвращение восстанавливает instanceId, HP, комнаты, ранее посещённые этажи и очередь возрождения; место прибытия берётся из текущего серверного входа. Снимок удаляется после восстановления, чтобы у населения оставался единственный владелец. Квестовый телепорт больше не удаляет весь прежний банк ради выбора нужного вида NPC.

Проверки доступа выполняются до перехода. Этап Хеллбаунда, пропуск, состав группы, ограничения Грации и исходная плата продолжают проверяться сервером. Отказ во входе не создаёт снимок и не переносит игрока.

Население инстанса сохраняется в его собственном состоянии. Публичный кеш не принимает инстансовые зоны, активный instanceId и палубы корабля Закена. Это сохранение публичных банков одной игровой сессии; общий межпользовательский банк NPC ещё не реализован.

Проверки:

- `node --test test/public-field-banks.test.js`: все 72 зоны с JSON-сохранением и восстановлением NPC/HP, свиток и оплаченный возврат в катакомбы, ограничения связанного входа, исключение инстансов/палуб, этажи и очередь возрождения.
- `ATLAS_ROOM_ZONE=catacomb-heretic,necropolis-sacrifice ATLAS_ROOM_START=room ATLAS_ROOM_SMOKE=1 ATLAS_ROOM_REENTRY=1 node scripts/ui/check-atlas-rooms.mjs`: на 320/1100 px выход свитком, сохранение игровой сессии и повторный вход через настоящий список Атласа; прежние HP и instanceId, отсутствие дубликатов и вторых окон. В PowerShell переменные задаются через `$env:`.
- Общая регрессия: 1844 теста без ошибок; два длительных сценария `arena auto-fight:` этим прогоном исключены.
