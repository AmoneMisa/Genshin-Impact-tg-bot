# Комнаты и этажи внутри Атласа

Атлас сохраняется открытым при входе в адаптированные комнаты: существующий компонент боя встраивается в его содержимое. Второе окно охоты и новый экземпляр Атласа не создаются. Быстрый телепорт, наземный подход и вход из церкви Руны используют этот же механизм.

В общем каталоге 72 неинстансовые зоны: 38 участков с мировыми XYZ и 34 зоны, пока использующие локальные комнаты. Все они доступны через один Атлас. Это завершение объединения экранов, **не завершение физической склейки мира**. В 34 адаптированных пространствах сохраняются локальные координаты, отдельные комнаты и проверяемые сервером переходы.

## Поведение

- Используется один компонент боя, его панель умений, припасы, чат, правила и диалоги переходов. Отдельной копии интерфейса нет.
- Встроенный режим отображает HTML/SVG и не загружает Phaser или WebGL. Отсутствие Canvas и рисунков не блокирует действия.
- Опросом состояния управляет Атлас. При просмотре мировой карты опрос охоты, анимация комнаты и её локальные таймеры останавливаются. Закрытие Атласа освобождает компонент, наблюдатели и обработчики.
- Начало боевого действия отменяет устаревшее чтение Атласа и приостанавливает следующий опрос до завершения действия. Ответ старого чтения не восстанавливает убитую цель.
- Escape останавливает движение или автоатаку, в том числе когда фокус находится в заголовке Атласа. При скрытой комнате обработчик не перехватывает закрытие карты.
- Возвращение свитком закрывает встроенное представление комнаты и показывает город в том же Атласе. Сервер сохраняет прежние банки и расходует свиток.
- Этажи, зеркала, односторонний прыжок под церковь Руны, палубы Закена и входы к боссам сохраняют прежние серверные ограничения. Переход к боссу не уничтожает компонент комнаты, который нужен после закрытия боя.

## Проверка

`node scripts/ui/check-atlas-rooms.mjs` проверяет настоящий серверный вход пешком в Круму, автоатаку, остановку через Escape, переход между этажами и обратно, JSON-сохранение с сохранением HP и instanceId NPC, мировой обзор, возвращение свитком, сохранение исходного DOM Атласа и Canvas, отсутствие переполнения и очистку после закрытия. Режимы: 320, 390 и 1100 px, 320 px без Canvas и 320 px без рисунков; reduced motion включён. Дополнительно пройдены три режима на коротком экране 320×640: обычный, без Canvas и без рисунков; кнопка перемещения остаётся внутри видимой области. Высоту можно задать через `ATLAS_ROOM_HEIGHT`.

Дополнительные запуски:

```powershell
# ТоИ и Ivory Tower: те же проверки боя и этажей.
$env:ATLAS_ROOM_ZONE='tower-of-insolence,ivory-tower'
node scripts/ui/check-atlas-rooms.mjs

# Церковь Руны -> односторонний прыжок -> зеркало -> Паган -> церковь.
$env:ATLAS_ROOM_ZONE='pagan-temple'
$env:ATLAS_ROOM_START='church'
node scripts/ui/check-atlas-rooms.mjs

# Настоящее создание рейса для группы -> палубы -> возвращение на первую палубу.
$env:ATLAS_ROOM_ZONE='devils-isle'
$env:ATLAS_ROOM_START='ship'
node scripts/ui/check-atlas-rooms.mjs

# Быстрый телепорт сохраняет тот же Атлас.
$env:ATLAS_ROOM_ZONE='cruma-tower'
$env:ATLAS_ROOM_START='quick'
node scripts/ui/check-atlas-rooms.mjs

# Задержанный ответ опроса пересекается с атакой; старая цель не возвращается.
$env:ATLAS_ROOM_ZONE='cruma-tower'
$env:ATLAS_ROOM_START='walk'
$env:ATLAS_ROOM_RACE='1'
$env:ATLAS_ROOM_WIDTH='390'
node scripts/ui/check-atlas-rooms.mjs
```

Отдельная обзорная проверка всех 34 адаптированных зон прошла на 320/1100 px: 68 случаев. Она создаёт начальное состояние комнаты серверным обработчиком, проверяет отображение, переключение обзора, возврат свитком и закрытие. Этот режим **не проверяет условия входа, бой и все этажи**:

```powershell
$env:ATLAS_ROOM_ZONE='adapted'
$env:ATLAS_ROOM_START='room'
$env:ATLAS_ROOM_SMOKE='1'
Remove-Item Env:ATLAS_ROOM_WIDTH -ErrorAction SilentlyContinue
node scripts/ui/check-atlas-rooms.mjs
```

Переменные сценария следует задавать в отдельном процессе либо удалять перед следующим запуском. `PLAYWRIGHT_PACKAGE` и `DESIGN_BROWSER` позволяют указать установленный Playwright и Chromium.

Проверка прежнего отдельного компонента на пяти многоэтажных локациях: 33 этажа в шести конфигурациях, 198 случаев. Общие контролы, динамические селекты, состояния и попапы прошли проверку на 320/390/820 px. Общая регрессия — 1834 теста без ошибок; два длительных сценария `arena auto-fight:` этим прогоном исключены. Сверка исходных территорий с Java — 27256 предложений.

## Что ещё не завершено

Физический перенос внутренних комнат и этажей в исходные XYZ, плавание, исходный вход и кампания Хеллбаунда, полный алгоритм видимости GeoEngine, специальный AI и динамические миньоны, общий межпользовательский банк NPC остаются отдельными задачами. Комнаты и изображения не считаются исходной геодатой. Четыре из 38 мировых полей подключены частично; недоступные исходные спавны явно перечислены в [реестре](native-field-registry.md) и [сверке геодаты](native-field-readiness.md).
