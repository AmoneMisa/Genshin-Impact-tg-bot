# Открытие заданий Академии

Причина: `openAcademy()` добавлял окно в DOM, но не включал класс `visible`. Общие стили `.game-overlay` оставляли его прозрачным с `pointer-events:none`. Обработчик городской кнопки дополнительно скрывал ошибки через пустой catch.

Исправление: окно получает `visible` после успешного рендера; отложенные стили загружаются перед открытием. Ошибка загрузки показывается в окне здания, кнопку можно нажать повторно. При неудачном переходе к профессиям Академия остаётся открытой и показывает ошибку.

Проверка: 24 теста `city.test.js`, `academy-forge-palace.test.js`, `i18n.test.js` прошли. Через настоящую городскую кнопку в Chromium на 320/390 px проверены видимость и интерактивность, загрузка feature CSS, ответ 503 и повторное открытие, неудачный и успешный переход к профессиям. Ошибок JS и горизонтального переполнения нет. API заменён фикстурами из серверных DTO; production Telegram/MongoDB не использовались.

Регрессионный браузерный скрипт: `scripts/ui/check-academy.mjs`. Требует Playwright; при внешней установке задаются `PLAYWRIGHT_MODULE` (путь к модулю) и `ITEM_ART_BROWSER` (Chromium). Результаты по умолчанию сохраняются в `.tmp/academy-check`, другой каталог задаёт `ACADEMY_CHECK_OUTPUT`.
