# Быстрый телепорт и исправление кнопок

«В город» остаётся доступной, даже если окно охоты добавлено после диалога смерти. Ссылки на функции, включая «Атлас», используют обработчик, работающий и для динамически созданных кнопок.

Быстрый ТП находится в Атласе (кнопка «Быстрый ТП», Alt+B). Города стоят 60 000 адены, охотничьи локации — три обычных тарифа. Обычный путь к хранителю портала сохранён. Входы в инстансы остаются у специальных NPC.

Сервер проверяет смерть, бой и зоны осады на отправлении и прибытии; цена берётся из каталога, плата списывается только после успешного перехода. Проверки браузером: 320, 390 и 820 px, включая активный менеджер модальных окон.
