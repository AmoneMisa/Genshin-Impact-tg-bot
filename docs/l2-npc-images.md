# Изображения NPC Lineage II

Подключены оригинальные скриншоты для 1037 из 1413 NPC текущего каталога охоты и рейд-боссов. Два размера WebP (до 128 и 256 px), суммарно 7.83 MiB. На игровом экране загружаются только изображения видимых NPC.

Привязка строго по NPC ID High Five; нет подмены похожим существом или общим рисунком класса. Это скриншоты из баз Lineage II, а не клиентские иконки и не анимированные модели. Сохраняются фон и пропорции исходника; преобразование ограничено уменьшением и WebP. База изображений может содержать снимки из разных хроник; точное соответствие каждого снимка внешности High Five не подтверждено.

Источники, SHA-256 исходников и размеры: `webapp/art/npcs/l2/source.js`. Обновление: `node scripts/l2j/import-npc-photos.mjs`; из локального кэша: добавить `--offline`.
