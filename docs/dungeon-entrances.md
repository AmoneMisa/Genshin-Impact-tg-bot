# Исходные внешние входы катакомб и некрополей

Метка Атласа использует NPC `DungeonGatekeeper` с исходной ролью `Role=0`. Внутренний `Role=1` и его удалённая точка назначения сохранены отдельно. Одинаковое имя Gatekeeper Ziggurat не означает одинаковую роль или расположение. Для каждого входа проверяются тип NPC, роль, SignNumber и единственная исходная позиция; записаны SHA-256 XML спавна и характеристик.

Привязка к поселению географическая: ближайший исходный городской NPC из материковых поселений nativeWorld. Говорящий Остров, остров Камаэль и Грация исключены: близость через море не делает материковый вход частью острова. Это группировка Атласа, а не границы владений. Контур выбора размером 1000×1000 — авторский охват Атласа, а не стены или геодата. Именованные координаты NPC не усредняются и не заменяются центром территории.

Фактические точки входа и выхода взяты из `teleporters/dungeon/ID.xml`, тип OTHER, индекс 0 из команды HTML. Старые PosX/PosY/PosZ в параметрах NPC сохранены отдельно: DungeonGatekeeper использует TeleporterData, а не эти параметры. По TeleportLocation отсутствие feeCount означает 0: все 14 переходов в исходной таблице бесплатны. Это цена перехода у зиккурата, а не городского быстрого телепорта.

Пеший подход через воду/двери остаётся неподтверждённым (`nativeGroundApproach=null`). Исправленная метка сама по себе не открывает новое пешее действие. В проекте нет серверного состояния цикла Семи Печатей (`sevenSignsStateAvailable=false`); оригинальные условия требуют регистрации в кабале, а в период действия печатей — проверки победителя и владельца соответствующей печати (Gnosis для катакомб, Avarice для некрополей). Исходник и SHA-256 сохранены; полноценный доступ Семи Печатей пока не реализован. Существующий проектный быстрый телепорт — отдельная старая механика; его цена не объявляется исходным тарифом зиккурата.

Источник: Mobius High Five `9fb01cb20513e55190cdde8d91e41be2c0914f84`. Воспроизведение: `node scripts/l2j/import-dungeon-entrances.mjs ID`, `node scripts/ui/report-dungeon-entrances.mjs`.

Старый `import-necropolises.mjs` теперь передаёт импорт входов этому генератору и не перезаписывает worldMap.js. Режим `node scripts/l2j/import-necropolises.mjs --entrances-only` обновляет все 14 входов без повторного импорта населения. Проверено повторное выполнение: исходный модуль Атласа и сгенерированные входы остаются неизменными.

Проверки: `node --test test/dungeon-entrances.test.js`; `DUNGEON_MAP_CHECK=catacomb-heretic node scripts/ui/check-native-world.mjs` — правильный регион в общем списке Атласа, отсутствие выдуманного пешего входа, 320/390/1100 px и 320 px без Canvas.
