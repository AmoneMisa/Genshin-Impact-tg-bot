# Персонаж, предметы, ATT и администрирование

## План и результат

1. **Тату и базовые статы:** передать нанесённые символы в снимке героя, показать оригинальные иконки красок и подписанные изменения рядом со статами; в деталях разделить вклад символов и прочие бонусы. Реализовано.
2. **Предметы:** связать старые ключи свитков с реальными предметами 736/737; заполнить понятные описания назначения материалов; исправить описание, ошибочно использованное как имя Forgotten Scroll; импортировать отсутствующие оригинальные клиентские иконки и проверить весь каталог. Реализовано, исходные пробелы перечислены в `audit.json`.
3. **Вайп:** сохранить подтверждение ID, сбросить общий персонаж в транзакции, отменить незавершённые столы с его участием, активные лоты и обмены; защитить общий персонаж от устаревших сохранений. Реализовано. Завершённые партии и персонажи других игроков не сбрасываются; незавершённые ставки ещё не списаны. Telegram-профиль и членство в клане сохраняются.
4. **Администрирование:** вход по Telegram-команде `/admin` и пути приложения `/admin`. Админка удалена из игровых карточек. Сервер и старые административные команды разрешают действия только `myId` из конфигурации. Подписанный `admin_chat_<id>` сохраняет выбор чата и не даёт дополнительных прав. `/unstack 21`, `/unstack elements` и старые команды сброса доступны только администраторам соответствующего группового чата, статус проверяется через Telegram перед выполнением.
5. **ATT:** единая серверная проверка совместимости используется для предпросмотра и установки. Все вещи остаются в сетке; несовместимые, временные, слишком низкого грейда, с противоположным атрибутом или достигнутым пределом показаны серыми и недоступны. Подмена запроса не тратит камни. Защиты брони используют противоположную стихию согласно существующей механике H5; до трёх защит без противоположных пар.
6. **Пустые слоты:** извлечь оригинальные текстуры из предоставленного клиента. Выполнено: `L2UI_CT1.utx`, `InventoryWnd.Inventory_DF_EquipSlot`, `Inventory_DF_EquipBg`, `Inventory_DF_EquipMask`. Общий модуль `l2-slot-background.js` подключает точные фрагменты атласа; исходные размеры и контрольные суммы записаны рядом с файлами. Клиент игры не изменялся.

## Данные и ограничения

Исходники: локальный датапак High Five в `.tmp/l2-high-five`, оригинальный набор PNG `C:/Users/kubai/Desktop/icons`, оригинальные текстуры `C:/Games/Scryde/SysTextures/L2UI_CT1.utx`. Описание назначения предмета формируется из исходного типа/категории; это не полный дословный перевод клиентских описаний. У оставшихся мгновенных трав исходные таблицы не задают иконку, поэтому похожие изображения им не назначались. Их список и результаты проверки опубликованных файлов находятся в `audit.json`.

Для чтения UE2-пакетов использован формат из [UEViewer, UnPackage2.cpp](https://github.com/gildor2/UEViewer/blob/master/Unreal/UnrealPackage/UnPackage2.cpp). Экспортёр проверяет сигнатуру, формат BGRA8, размер и границы исходного mip; неподдерживаемый формат приводит к ошибке вместо приблизительного результата. Нарезка слотов сохраняет пиксели, без перерисовки и масштабирования.

Проверки: серверные тесты прав, вайпа и совместимости ATT; проверки UI на 320/390/1100 px, проверки инвентаря и подтверждения вайпа на 320/390/820/1100 px. UI проверяется с reduced motion, фокусом, disabled, открытием/закрытием окон и отсутствием горизонтального переполнения. Вайп проверяется на тестовых моделях; реальный персонаж в рабочей базе не удалялся.
