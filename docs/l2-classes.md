# Классы Lineage 2 (High Five)

Игра использует реальное дерево классов High Five вместо прежних 6 баз и 24 профессий.

## Дерево

| Ступень | Реальный класс | Уровень | `tier` |
|---|---|---|---|
| Стартовый класс | Fighter / Mystic каждой расы, солдаты камаэль | 1 | 1 |
| 1-я профессия | Warrior, Knight, Rogue, Wizard, Cleric ... | 20 | 2 |
| 2-я профессия | Gladiator, Paladin, Sorcerer, Bishop ... | 40 | 3 |
| 3-я профессия | Duelist, Phoenix Knight, Archmage, Cardinal ... | 76 | 4 |

- 11 стартовых классов: человек (боец, мистик), эльф (боец, мистик), тёмный эльф (боец, мистик), орк (боец, мистик), гном (боец), камаэль (муж. и жен. солдат).
- 92 профессии, включая линии камаэль: Trooper → Berserker / Male Soul Breaker → Doombringer / Male Soul Hound, Warder → Female Soul Breaker / Arbalester / Inspector → Female Soul Hound / Trickster / Judicator.
- Данные дерева — `template/l2Classes.js` (генерируется `scripts/l2j/extract-classes.py` из датапака L2J Mobius High Five); имена, боевая «линия» и родитель — `template/l2ClassMeta.js`.
- Татуировки требуют 2-ю профессию (`tier` 3, уровень 40), как в оригинале.

## Боевые линии (family)

Каждый класс сражается в одной из шести линий: `warrior` (танки и рыцари), `berserk` (ближний бой), `rogue` (кинжалы), `archer` (луки и арбалеты), `mage`, `priest`. Линия выбирает носителя экипировки, набор баффов и вес характеристик. Характеристики профессии — форма (`like`) одной из прежних профессий, решённая до силы ступени: `template/classTree.js`, калибровка по арене — `scripts/balance/calibrate-tree.mjs` и `scripts/balance/apply-tune.mjs`.

## Навыки

- Боевой набор: слоты 0–2 — база линии, далее по два навыка за профессию из **реального дерева** этого класса, у 3-й профессии ещё два пробуждённых (уровни 76 и 80, нужна сущность босса). Названия реальные; урон, откат и мана соразмерены движку (`template/professionSkills.js`).
- Баффы и дебаффы по реальным таблицам уровней — слой `functions/game/player/l2Effects.js`; в нём класс учит навыки своего дерева и родителей.
- Пассивные навыки (`functions/game/player/passiveSkills.js`): реальные пассивы дерева, по уровню за раз. Цена — реальные ОП, уменьшенные в 20 000 раз; нужный уровень персонажа реальный; книги умений — материалы `l2_<id>`. Бонус реальный (прибавка к атаке, защите, HP...), привязанный к оружию/броне условием («при луке», «в лёгкой броне»).
- Клановые навыки (`functions/game/clans/clanPerks.js`): реальное дерево клана (Clan Body, Clan Might ...), реальный уровень клана, репутация ×0,5, золото склада и яйцо эпического босса. Навыки без эффекта в игре (сопротивления контролю, Clan Imperium) изучаются, но ничего не дают; замковые и территориальные навыки выдаёт замок.

## Перенос персонажей

`migrateSessionClass` (при загрузке сессии) переводит прежний класс в ближайший реальный по уровню (`functions/game/classes/legacyClasses.js`): Warrior → Human Fighter, Archer → Rogue / Hawkeye, Phoenix Knight → Paladin и т. д.; уровни умений слотов сохраняются. Старые имена классов ещё читаются (`resolveClassName`).

## Ограничения этого этапа

- Описания навыков генерируются на русском по числам навыка; узбекский перевод есть для имён классов, фраз квестов и шаблонов описаний.
- Не все эффекты реальных навыков есть в движке: призыв, превращения и воскрешение в боевой набор не попадают.
- Калибровка по арене проведена по ступеням, пока в процессе; текущие результаты — `node scripts/balance/calibrate-tree.mjs --check` с `TIER=2|3|4`.
