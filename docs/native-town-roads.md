Граф соединяет девять городов и поселений: Глудин, Глудио, Дион, Флоран, Гиран, Хейн, Орен, Деревню Охотников и Аден. Прежний разрыв Глудио — Дион устранён; можно пройти из Глудина до Адена и обратно. Длинный путь проходит через промежуточные города без переноса персонажа и оплаты. Остановка, новая цель, обездвиживание и сохранение/загрузка сохраняют реальный бюджет движения.

Прямой путь Орен — Аден содержит 47 точек и имеет длину около 97583 игровых единиц вместо 140229 через Деревню Охотников. Граф выбирает новый путь, когда он короче. Оба направления проверены по всем исходным клеткам; исходные городские точки и цены телепортов сохранены.

Отдельная северная связь соединяет Руну и Годдард: 63 точки, около 141497 игровых единиц. Из Годдарда можно пройти к Ферме зверей через Руну и вернуться, сохранив банк NPC. Северная связь пока не соединена с основной сетью девяти городов.

Связь Гиран — Орен проходит по подтверждённым участкам у Долины Драконов и Равнин Ящеров с проверенным наземным соединением между ними. Это проходимый обход; кратчайшая дорога не гарантируется. Глудио — Дион подтверждён поиском от Диона с шагом 64 единицы и последующей проверкой всех исходных 16-единичных клеток в обе стороны. Аден — Годдард, Орен — Руна и Годдард — Шутгарт пока не подтверждены. Неудача ограниченного поиска не означает отсутствия дороги в оригинальной игре.

Для Руна — Годдард применён офлайн-поиск с двух сторон. Начальные тропы — уже проверенные наземные отрезки; соединение фронтов также проверяется в обе стороны по всем исходным клеткам. Сборщик умеет использовать известные компоненты дорог и уменьшать шаг возле препятствия до одной клетки. Слои при одинаковых XY не объединяются. Это улучшение построения маршрутов; в телефоне и игровом серверном обработчике такой расширенный поиск не запускается.

В Атласе откройте «Перемещение» → «Города», выберите связанный город и «Дойти пешком». Флоран доступен пешком в том же списке, даже если платного телепорта нет. Кнопка учитывает блокировку действий. Без Canvas список и остановка продолжают работать. Геодата остаётся на сервере; телефон получает только ближайшие точки маршрута.

Пешее действие на городском маркере Флорана/Диона теперь использует тот же сохраняемый геодатный путь, что и общий список перемещения. Старый перенос по таймеру для этого действия удалён; карта сразу показывает фактический путь. Проверки блокировки действий и остановка общие.

Обычное нажатие на землю за исходной границей города теперь начинает наземный путь в мировых координатах. При завершении свободного пути внутри исходного объёма TownZone персонаж входит в город в достигнутой точке и на достигнутой высоте, без переноса к хранителю портала. Клиент не задаёт высоту или этаж. Учитываются NSWE, закрытые двери, вода и владения. Дальность нового свободного нажатия ограничена 8192 единицами, поиск — 6000 узлами.

Возобновление из сохранённой точки сначала проверяет до 64 прямых соединений с ближайшими тропами, затем сохраняет прежние шесть локальных попыток A*. Это устраняет случай, когда первые кандидаты лежали на другой стороне препятствия и поиск пропускал доступный прямой проход. Высоты, NSWE, вода, владения и обратный проход проверяются для каждого соединения. Бюджет A* не увеличен, полные пути остаются на сервере.

Связанные охотничьи зоны разных городов используют те же дороги. Например, Долина Драконов → Поле Безмолвия проходит через Гиран и Хейн. Выход из боевой комнаты требует физического подхода к её входу; проверки уровня, группы, региона и проходок сохраняются. Возвращение восстанавливает единственный банк NPC с прежними HP и instanceId.

## Ограничения

Боевые комнаты пока используют адаптированное локальное пространство. На межгородских дорогах ещё нет населения и боя/PvP. Плавание и динамические двери не подключены. Острова, Грация, подземелья, этажи, корабль Закена и инстансы не получают автоматических связей. Другие направления требуют отдельного подтверждения исходной геодатой.

## Воспроизведение

- `node scripts/l2j/import-geodata.mjs --town-routes` — исходные регионы для дорог и обходов.
- `node scripts/l2j/build-native-town-routes.mjs` — ограниченный офлайн-поиск и полная проверка отрезков; можно передать ID пары, например `dion:gludio`. Подтверждённые дороги по умолчанию повторно проверяются без нового поиска; `--rebuild` запускает поиск заново. `--reverse-only` запускает только поиск от целевого города. Бюджеты игровых действий не меняются.
- `node scripts/l2j/build-native-town-routes.mjs --meeting-only goddard:rune` — офлайн-поиск с двух сторон; для уже подтверждённой дороги выполнит повторную проверку. `--rebuild` исключает старую дорогу из начальных троп и ищет заново.
- `node --test test/native-town-travel.test.js test/native-travel.test.js test/city-navigation.test.js`.
- `TOWN_ORIGIN=oren TOWN_DESTINATION=aden node scripts/ui/check-native-towns.mjs` — прямой путь.
- `TOWN_ORIGIN=gludin TOWN_DESTINATION=aden node scripts/ui/check-native-towns.mjs` — длинная цепочка с остановкой.
- `TOWN_ORIGIN=goddard TOWN_DESTINATION=rune node scripts/ui/check-native-towns.mjs` — браузерный сценарий северной связи.
- `TOWN_ORIGIN=floran TOWN_DESTINATION=dion TOWN_MARKER=1 node scripts/ui/check-native-towns.mjs` — городской маркер и запасной список.
- `node scripts/ui/report-native-towns.mjs` — этот отчёт.

Морской переход Глудин — Руна соединяет компоненты через исходный корабль и проверенные подходы к портам; он не считается наземной дорогой. [Транспорт](native-transport.md).
