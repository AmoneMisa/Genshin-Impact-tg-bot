# Категории навыков клиента High Five

В `template/l2SkillGroups.js` импортировано поле `skillgrp.icon_type` для всех 984 навыков `template/l2Classes.js`: 42 936 записей с обычными и зачарованными уровнями. Распределение больше не вычисляется по названию, типу операции или эффектам навыка.

Два публичных архива клиента High Five сверены по каждой импортируемой паре ID/уровень. Категории совпали во всех 42 936 записях. Это сторонние зеркала файлов клиента, а не опубликованный NCsoft эталон: совпадение двух архивов подтверждает импортируемые значения, но не доказывает неизменность остальных полей клиента. Полные файлы, сторонние исполняемые программы и пользовательские навыки этих сборок в проект не добавляются.

После загрузки двух файлов по закреплённым URL из `sources`:

```powershell
node scripts/l2j/import-skill-groups.mjs <первый-skillgrp.dat> <второй-skillgrp.dat>
```

Импорт проверяет хеши, формат, длины, допустимые категории, уникальность ID/уровня, окончание таблицы, наличие каждого навыка проекта и согласие двух источников. Неизвестный или изменённый источник требует явного обновления источников и проверки; импорт не дополняет пропуски догадками.

## Соответствие разделам

| icon_type | Раздел |
|---|---|
| 0 | Физические навыки |
| 1 | Магические навыки |
| 2 | Усиливающие навыки |
| 3 | Ослабляющие навыки |
| 4 | Клановые навыки |
| 5 | Предметные навыки |
| 6 | Переключаемые навыки |
| 7 | Трансформации |
| 11 | Навыки экипировки |
| 12 | Особые способности |
| 13 | Расовые навыки |
| 14 | Профессиональные навыки |
| 15 | Клановые и героические навыки, пассивные |
| 16 | Предметные способности, пассивные |

Категория выбирается для конкретного клиентского уровня. При заточке используется `route * 100 + enchantLevel`; при нулевой заточке — обычный уровень. Поэтому Prominence +1 по третьему пути попадает в ослабляющие навыки, а по первому остаётся магическим. Anti Magic и Lucky относятся к особым способностям, Expertise и Create Common Item — к навыкам экипировки.

Для ещё не изученного пассивного навыка берётся доступный уровень. Неизвестные ID и уровни показываются в явно общих разделах «Другие активные навыки» / «Другие пассивные навыки». После расширения каталога нужно повторить импорт; тест покрытия проверяет наличие обычных уровней каждого навыка. Источники описания, иконок, эффектов, обучения и стоимости заточки этим импортом не изменяются.
