# Эмблемы классов

Заголовок персонажа использует именованные эмблемы профессий Lineage II. Портрет персонажа, пол и аватар больше не участвуют в выборе изображения заголовка. Для `humanKnight` используется `knight.webp`, для `paladin` — `paladin.webp`, для `phoenixKnight` — `phoenix_knight.webp`.

Источник изображений и названий: [каталог классов L2Bandit](https://l2bandit.camp/classes). Исторический набор эмблем вторых профессий также опубликован в [архиве сайта Lineage II](https://legacy-lineage2.com/Knowledge/subclasses_2.html). Это опубликованные эмблемы классов, а не извлечённые текстуры локального клиента; оригинальные файлы источника сохранены без перерисовки и перекрашивания.

Сопоставлены 89 классов дерева проекта. В этом наборе отсутствуют 14 профессий Камаэль; они явно показывают отсутствие подтверждённого изображения. Аналогичный класс, навык или портрет вместо эмблемы не подставляется. Импорт: `scripts/l2j/import-class-emblems.mjs`; таблица: `webapp/art/l2-class-emblems.js`; изображения: `webapp/art/l2-classes/`. Контрольные суммы скачанных файлов записаны в `.tmp/class-icons/manifest.json`.
