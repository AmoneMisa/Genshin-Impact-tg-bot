# Исправления Mini App, 11 октября 2026

## Интерфейс и навигация

- Кнопки закрытия в правом верхнем углу, с отступом 10 px и небольшим крестиком. Область касания 44 px.
- Исправлена блокировка нативного диалога количества: внесение, отмена и Escape работают в хранилище.
- Добавлена быстрая кнопка текущего задания с целью и прогрессом. Переход ведёт прямо к мировым боссам; ошибка загрузки сохраняет окно задания и позволяет повторить переход.
- Убрана отдельная карточка «Торговцы». Рыбалка, древняя адена и полный каталог доступны из магазина. Сохранены серверные проверки покупок и обмена.
- Мобильная форма магазина перестроена в одну колонку: название ресурса и цена не перекрываются, внутренние рамки убраны.
- Профессии имеют компактные отступы, подсказки о добыче квестовых предметов и назначении наград. Вместо иконки S-кристалла показана обычная валюта «кристаллы».
- Исправлены пустые слоты украшений и описание человеческой ветки магов.
- Доступ к админке определяется владельцем на сервере; она скрыта у остальных игроков.

## Игровая логика

- Убраны ограничения Mini App по типу Telegram-чата, включая смену пола.
- Бесплатные пассивные навыки оригинальной таблицы автоматически изучаются при достижении нужного уровня, без списания SP. Платные навыки сохраняют обычное обучение.
- Для недостающего материала показан быстрый крафт, если рецепт изучен и хватает уровня, профессии, MP, ингредиентов и места. Используется обычная серверная операция крафта с её шансом успеха.
- Базовые HP/MP/CP, характеристики и скорость берутся из таблиц классов High Five. Старый экспоненциальный рост атаки/защиты заменён для реальных классов. Миграция сохраняет долю текущих ресурсов, включая состояние смерти, и выполняется один раз.
- Это базовые параметры без экипировки; полный баланс боёв со всеми наборами снаряжения требует отдельной проверки. Старые тесты относительного баланса шести условных классов оставлены на прежних калибровочных параметрах; для новой таблицы добавлены отдельные проверки реальных классов, миграции и завершения дуэлей.

## Ошибки открытия и база данных

Обычное чтение почты и списка охотничьих полей больше не требует ненужного сохранения через транзакцию. Возврат просроченных вложений, бой и изменения инвентаря сохраняют атомарность. Ошибка MongoDB без поддержки транзакций возвращает понятный ответ 503 вместо общего 500.

В локальной базе подтверждён режим standalone. Состояние базы продакшена не проверено: нужны серверные логи и проверка конфигурации. Проверка ниже ничего не меняет и не выводит адрес или пароль:

```powershell
node --env-file=.env scripts/models/checkTransactions.mjs
```

Для Docker выполнить внутри работающего контейнера бота:

```sh
docker compose exec bot node scripts/models/checkTransactions.mjs
```

Ожидаемый результат — `transactionsSupported: true`. В `docker-compose.yml` уже настроен single-node replica set `rs0`. Если используется внешняя база, потребуется replica set или sharded cluster. Перед изменением существующей базы необходима резервная копия; этот патч не меняет её топологию и не запускает миграцию инфраструктуры.
