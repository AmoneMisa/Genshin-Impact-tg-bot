# Общая сетка предметов

Сетка инвентаря, магазинов, личного и кланового хранилища, обмена использует один компонент webapp/item-grid.js и один набор стилей webapp/item-grid.css.

Тёмный плоский фон, квадратные клетки без отступов, тонкие границы, выделение золотом. Последняя строка заполняется пустыми клетками при изменении ширины окна. Счётчики, заточка, розовые границы теневых предметов и действия сохранены. Надетое снаряжение исключено из сумки.

Проверки в Chromium: магазины и обмен/хранилища — 320, 390, 1100 px; инвентарь — 320, 390, 540, 1100 px. Покупка, использование последнего зелья, выброс, выставление на аукцион, внесение/вывод и завершение обмена проверены.
