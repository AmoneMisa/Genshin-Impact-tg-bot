# Оригинальные изображения боссов Lineage II

В список мировых боссов, портрет цели и сцену боя подключены локальные оригинальные снимки NPC: 11 эпиков и 224 рейд-босса. Картинки сохраняют пропорции; в бою остаются реакции на попадание, атаку и смерть. Сгенерированные картины сохранены отдельно.

Локации всех эпиков отображаются в карточках на русском, с английскими названиями основных зон для поиска.

Источники снимков: [L2ELO](https://l2elo.com/en/database/npcs/type/l2raidboss), [L2DB](https://l2db.ru/), [L2Vika](https://l2vika.ru/highfive/new-mobs/new-mobs-highfive-80-90-level.html), [Lineage2Dex — Freya](https://wiki.lineage2dex.com/freya-ice-queen/en). Водяные знаки источников сохранены. Фрея и её экстремальная версия используют один оригинальный образ.

Соответствия имени, ID NPC, локального файла и URL источника находятся в `webapp/art/bosses/l2/manifest.json`. В его разделе `missing` перечислены 50 РБ, для которых оригинальный снимок в проверенных каталогах не найден. Заглушки каталогов исключены. Таким РБ не назначается изображение другого NPC.

Повторный импорт: `node scripts/l2j/import-boss-photos.mjs`. Уже сохранённые оригиналы используются повторно. Проверки соответствий: `node --test test/l2-boss-art.test.js`; проверка мобильного интерфейса: `scripts/ui/check-l2-boss-art.mjs` (Playwright, переменные `PLAYWRIGHT_PACKAGE` и `DESIGN_BROWSER`).
